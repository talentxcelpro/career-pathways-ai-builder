## 4. Verification & Link Health Telemetry

Every backlink in the system is subject to the **Live Verification Engine**:
1. High-speed HTTP GET crawler requests the target page with standard desktop user-agents.
2. Follows redirects to final destination.
3. Parses HTML DOM to extract all `<a>` tags referencing `talentxcel.in`.
4. Inspects `rel` attributes (`follow`, `nofollow`, `ugc`, `sponsored`).
5. Extracts and normalizes actual published anchor text.
6. Flags status:
   - **LIVE:** Backlink confirmed in DOM with HTTP 200.
   - **LOST:** Page responded with HTTP 200, but TalentXcel link was removed.
   - **MODIFIED:** Anchor text or rel attribute changed since prior audit.
   - **BROKEN:** HTTP 404, 410, or DNS error.
   - **ERROR:** Timeout or 5xx server failure.
