### 5.2 Rejected Candidate Platforms & Root Cause Audit
During platform qualification, four publishing platforms were tested and rejected in accordance with our strict verification standards:

1. **Write.as (`write.as`):**
   - *Result:* API returned HTTP 200, but live crawler inspection proved Write.as renders markdown syntax as raw `<p>` plain text without HTML `<a>` tags.
   - *Status:* **REJECTED (Platform Rendering Limitation)**.
2. **Dpaste.org (`dpaste.org`):**
   - *Result:* API created paste `https://dpaste.org/Stpdw`, but crawler inspection returned HTTP 403 Cloudflare Security Check.
   - *Status:* **REJECTED (Bot/Crawler Barrier)**.
3. **ControlC (`controlc.com`):**
   - *Result:* Submission endpoint returned HTTP 403 due to Cloudflare anti-bot WAF.
   - *Status:* **REJECTED (WAF Ingestion Barrier)**.
4. **Telegra.ph (`telegra.ph`):**
   - *Result:* Account creation failed with `read ECONNRESET` at the regional network transport layer.
   - *Status:* **REJECTED (Network Transport Failure)**.
