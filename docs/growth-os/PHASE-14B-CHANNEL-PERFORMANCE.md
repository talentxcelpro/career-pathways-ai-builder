## 1. The Six Rigor Classification Levels

To prevent declaring an acquisition engine "successful" simply because code or a landing page exists, every channel is audited across six progressive maturity levels:

```
Level 1: Implemented ──────────▶ Code exists in repository
Level 2: Technically Operational ──▶ Builds, runs, schemas valid, routes resolve 200 OK
Level 3: Receiving Genuine Visitors ▶ Organic non-bot human sessions arriving
Level 4: Generating Registrations ─▶ Visitors converting to email-verified accounts
Level 5: Producing Retained Users ──▶ Users returning at Day 7 / Day 28
Level 6: Economically Scalable ─────▶ Acquisition cost (CAC) < Lifetime value (LTV)
```
