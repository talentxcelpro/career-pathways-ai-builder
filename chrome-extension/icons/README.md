# TalentXcel Extension Icons

This directory should contain the following icon files:

- `icon16.png` - 16x16 px icon for extension UI
- `icon32.png` - 32x32 px icon for extension UI and FAB
- `icon48.png` - 48x48 px icon for extension management
- `icon128.png` - 128x128 px icon for Chrome Web Store

## Icon Guidelines

- Icons should be in PNG format
- Use the TalentXcel brand colors and logo
- Ensure icons are clearly visible at all sizes
- Background should be transparent for 16px and 32px icons
- Use solid background for 48px and 128px icons

## Temporary Placeholders

Until proper icons are created, you can use placeholder icons or simple colored squares with the "TX" initials.

Example colors to use:
- Primary: #667eea
- Secondary: #764ba2
- Gradient: linear-gradient(135deg, #667eea 0%, #764ba2 100%)
